# 规则模板

## 证件类型↔证件号码一致性

当证件类型为'居民身份证'时，证件号码必须为18位，符合GB 11643标准。

```
条件：证件类型 LIKE '%身份证%' OR 证件类型 = '01'
且：证件号码长度 != 18
```

---

## 性别↔身份证号奇偶性

身份证号第17位奇偶性应与性别代码一致：
- 奇数为男（性别代码=1）
- 偶数为女（性别代码=2）

```
条件：身份证号长度=18
且：(性别='1' AND 身份证号第17位%2=1) OR (性别='2' AND 身份证号第17位%2=0)
```

---

## 日期合理性

日期字段不应晚于当前日期。

```
条件：日期 IS NOT NULL AND 日期 > 当前日期
```

---

## 姓名文本规范

姓名不应包含首尾空格、非法特殊字符。

```
条件：TRIM(姓名) != 姓名
```

---

## 联合元素完整性

姓名和证件号码不能同时为空。

```
条件：(姓名 IS NULL OR 姓名='') AND (证件号码 IS NULL OR 证件号码='')
```

---

## 记录数量合理性

维度表每个自然人只能有一条记录。

```
条件：COUNT(*) > 1（按主键分组后记录数>1）
```

---

## 测试数据检测

字段中不应包含明显的测试特征值。

检测关键词：
- 测试、TEST、test
- 示例、SAMPLE
- demo、DEMO
- 0000、1111、XXXX
